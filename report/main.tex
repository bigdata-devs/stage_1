\begin{abstract}
This report documents the design and the controlled evaluation of the Stage 1
data layer: a synchronous ingestion pipeline (datalake), metadata extraction,
and three inverted-index structures, implemented in Python and ported to Go,
Rust and Java. The evaluation answers one question: \emph{which language and
storage combination behaves best for this corpus and this workload}, under a
single measurement protocol. Before any timing is interpreted, the four
implementations are shown to be behaviourally equivalent (byte-identical
canonical outputs, SHA-256
\fixed{cdaa9369cbd91c4f89550efdcdd7c5c21e61adc97bd49f6e415b8e57d65ce2e4}).
All results come from one reproducible tournament
(\texttt{scripts/run\_tournament.sh}) whose raw CSVs, environment record and
revision identifier are committed next to this document. Claims are
deliberately scoped to the tested corpus, host and workload; unmeasured
behaviours are listed in \cref{sec:limitations}.
\end{abstract}
