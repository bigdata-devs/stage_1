\section{Reproducibility}
\label{sec:reproducibility}

Every figure in this report is reproducible from the repository at a single
identified revision. The full protocol is documented in
\texttt{REPRODUCING.md}; the short version follows.

\paragraph{One command.}
\texttt{./scripts/run\_tournament.sh} runs six phases in order and refuses
to time anything before equivalence passes:

\begin{enumerate}
    \item \textbf{equivalence} --- cross-language canonical files, compared
    byte for byte (\texttt{equivalence\_\allowbreak report.json});
    \item \textbf{download} --- \fixed{5} probe rounds per language, run
    round-robin on one pinned core, so the network sample of the four
    languages is interleaved;
    \item \textbf{benchmarks} --- Go, Rust, Java (+JMH) and Python suites,
    each pinned to one logical core, writing its CSVs under
    \texttt{benchmarks\_\allowbreak results/\allowbreak <language>/};
    \item \textbf{verify} --- schema check of every CSV
    (\texttt{src/\allowbreak utils/\allowbreak benchmarks/\allowbreak verify\_\allowbreak format.py});
    \item \textbf{environment} --- host, runtimes and Git revision in
    \texttt{benchmarks\_\allowbreak results/\allowbreak environment.txt};
    \item \textbf{charts} --- \texttt{src/\allowbreak visualizations/\allowbreak main.py} renders \texttt{charts/}.
\end{enumerate}

There is no resume: a failed run restarts clean, so the committed snapshot
always comes from one continuous execution.

\paragraph{Revision.}
The Git commit that produced the committed snapshot is recorded inside
\texttt{benchmarks\_\allowbreak results/\allowbreak environment.txt} together with the host and
runtime versions of \cref{tab:host}: \texttt{0482a5e} for the current
snapshot, whose results were committed in \texttt{9e53348}; the previous
snapshot compared in \cref{sec:refactor-effect} is \texttt{28d4c3f}, produced
by \texttt{b104a9a}. Checking out a commit and re-running the command above
reproduces the pipeline; the raw numbers will differ (shared-host jitter,
\cref{sec:limitations}) while the equivalence digests stay fixed. Whether the
orderings reported here are stable across runs has not yet been tested with a
second run (\cref{sec:future}).
